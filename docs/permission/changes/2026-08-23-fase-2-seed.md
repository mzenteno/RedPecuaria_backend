## Qué cambió

Se insertaron 4 filas en `role_menu_permissions` para el rol "Administrador": una por cada
menú hijo del seed (Empresas, Usuarios, Roles, Permisos), cada una con
`can_view/can_create/can_edit/can_delete = true`.

construidas para poder operar el sistema desde el primer login.
